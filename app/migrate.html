Projexa — Screen Tracking

ทะเบียนหน้าจอ

ย้ายเอกสาร screens ไปใช้ id แยกจาก code

เครื่องมือใช้ครั้งเดียว (one-time) — เดิม document id ของ screens คือรหัสหน้าจอ (code) ตรงๆ ตอนนี้เปลี่ยนให้ document id เป็น Firestore auto-generated id (ฟิลด์ screens_id) แทน ส่วน code เป็นฟิลด์ label แยกที่แก้ไขได้อิสระ — กดปุ่มด้านล่างเพื่อย้ายเอกสารเก่าที่ยังเป็นสคีมาเดิมทั้งหมด

คำเตือนก่อนกด

  • เป็นการแก้ไขข้อมูลจริงบน Firestore project ที่ตั้งค่าไว้ใน js/firebase-config.js โดยตรง
  • เอกสารเดิม (doc id = code) จะถูกคัดลอกไปเป็นเอกสารใหม่แล้วลบเอกสาร/ประวัติเดิมทิ้ง — ควร export ข้อมูลสำรองจาก Firebase Console ไว้ก่อนถ้ากังวล
  • กดซ้ำได้อย่างปลอดภัย — เอกสารที่ย้ายแล้ว (มีฟิลด์ screens_id ตรงกับ doc id อยู่แล้ว) จะถูกข้าม ไม่ย้ายซ้ำ
  • รันครั้งนี้ครั้งเดียวหลังอัปเดตโค้ดแอป ไม่ต้องรันซ้ำในการใช้งานปกติ
