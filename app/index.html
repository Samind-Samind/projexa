Screen Tracking — โมดูล Screen Tracking (ขอบเขต NoSQL)

โค้ดจริง (ไม่ใช่ prototype) ที่ต่อ Firestore project จริงตรงๆ จากเบราว์เซอร์ — ดูขอบเขตที่ SCOPE.md และโครงสร้างข้อมูลที่ docs/02-design/02-technical/screen-tracking-nosql-module.md

เริ่มต้นใช้งานครั้งแรก

  1. ใส่ firebaseConfig ของ project จริงใน js/firebase-config.js (ทำแล้ว)
  2. เปิด Firestore Database ใน Firebase Console แล้ว publish firestore.rules
  3. เปิด Authentication → Sign-in method → เปิดใช้ Email/Password ใน Firebase Console
  4. เปิด สมัครสมาชิก เพื่อสร้างบัญชีผู้ใช้ (ต้องล็อกอินก่อนถึงจะใช้งานหน้าจออื่นได้)
  5. เปิด seed.html กด "เริ่มใส่ข้อมูลตัวอย่าง" ครั้งเดียว (ต้องล็อกอินแล้ว)
  6. เปิด ทะเบียนหน้าจอ — ควรเห็นข้อมูลจริงจาก Firestore

หน้าจอในสโคปนี้

  • SCR-009 — ทะเบียนหน้าจอ
  • SCR-010 — รายละเอียดหน้าจอ (สร้าง/แก้ไข + AI แนะนำประเภท)
  • SCR-013 — มอบหมายผู้รับผิดชอบ
  • SCR-016 — บันทึกความก้าวหน้า

ต้อง เข้าสู่ระบบ ก่อนจึงจะใช้งานหน้าจอเหล่านี้ได้ — firestore.rules บังคับ request.auth != null

เครื่องมือดูแลระบบ (ใช้ครั้งเดียว)

ถ้าเคยสร้างข้อมูลหน้าจอไว้ก่อนที่ document id จะแยกออกจากรหัสหน้าจอ (code) ให้เปิด migrate.html เพื่อย้ายเอกสารเก่าไปใช้สคีมาใหม่ครั้งเดียว
