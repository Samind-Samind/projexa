## Sync ฟิลด์ due_date เข้า Assignment (Database Schema / API Spec)

- ตาราง/resource ที่ทำรอบนี้:
  - `Assignment` (database-schema.md) — สถานะ `Draft (suggested)` (ไม่เปลี่ยน)
    — เพิ่มฟิลด์ `due_date` (DateTime, nullable) ต่อจากแถว `role`
  - `Assignment` (api-spec.md) — สถานะ `Draft (suggested)` (ไม่เปลี่ยน) — แก้
    request body ของ operation "Batch assign" (`POST /assignments/batch`)
    จาก `[{screen_id, user_id, role}]` เป็น `[{screen_id, user_id, role,
    due_date?}]`
- Sync §4.1/§7.1: ไม่ได้ sync (user ยืนยันว่าเป็นแค่เพิ่มฟิลด์ในตารางเดิม
  ไม่ใช่ entity/AI component ใหม่ ไม่ต้อง sync เอกสารหลักรอบนี้)
- บริบท: sync ตามประเด็นเปิดที่พบตอนทำ Detailed Design ของ
  [[../02-design/02-technical/detailed-design/scr-013-มอบหมายผู้รับผิดชอบ|SCR-013
  detailed design]] — ฟอร์ม batch assign ใน prototype มีการตั้งวันส่งงาน
