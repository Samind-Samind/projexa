เปลี่ยนสถานะความก้าวหน้า

สถานะปัจจุบัน: Analysis · อัปเดตล่าสุด: 25/08/2026 09:00

กรุณากรอกเหตุผลก่อนบันทึก เนื่องจากเป็นการถอยสถานะ (AC-NOSQL-016-2)

การเดินหน้าสถานะตามปกติ (เช่น Not Started → Analysis → Design) ไม่บังคับกรอกเหตุผล — บังคับเฉพาะตอนเลือกสถานะที่ถอยหลังเท่านั้น

ลองกดปุ่ม "Design" แล้วกลับไปกด "Analysis" (ถอยสถานะ) เพื่อทดสอบว่าระบบบังคับกรอกเหตุผล เทียบกับกด "Design" ตรงๆ (เดินหน้าปกติ) ที่ไม่บังคับ

ทดสอบกรณีหน้าจอถูกลบไปแล้วก่อนกดบันทึก (AC-NOSQL-016-4): — หลังกดแล้วลองกด "บันทึกความก้าวหน้า" จะเห็นข้อความแจ้งเตือนว่าหน้าจอนี้ไม่มีอยู่แล้ว แล้วพากลับไปหน้าทะเบียนหน้าจอ แทนการบันทึกลง statusHistory ของเอกสารที่ไม่มีอยู่จริง
