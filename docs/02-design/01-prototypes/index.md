# 01 - Prototypes

เก็บ **ต้นแบบหน้าตาของระบบ (UI/UX Prototype)** เช่น

- Wireframe / mockup ของแต่ละหน้าจอ
- User flow และ navigation flow
- [[DESIGN|DESIGN]] — Design System เต็มรูปแบบ (Brand Identity, Design Tokens, Components, UX Guidelines) โทน "Warm Terracotta Workspace" (Sand & Cream + Terracotta & Sage) ตามไฟล์อ้างอิง `Projexa.html`
- [[user-journey|user-journey]] — User journey ภาพรวมและรายบุคคล (Draft, สังเคราะห์อัตโนมัติ)
- Prototype เวอร์ชันล่าสุด: [v2](v2/index.html) — สโคป: SCR-009/010/013/016 โมดูล Screen Tracking (ขอบเขต NoSQL — งานส่งหลักสูตร) (Confirmed)
- เวอร์ชันก่อนหน้า: [v1](v1/index.html) — สโคป: SCR-003 ข้อมูลโครงการ (Draft, คนละสโคปกับ v2 — ระบบ Projexa จริงเต็มรูปแบบ)
