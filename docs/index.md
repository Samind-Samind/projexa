# Docs

ศูนย์รวมเอกสารทั้งหมดของโปรเจกต์ **My Coffee Store** จัดเรียงตามลำดับการไหลของงาน (workflow) ตั้งแต่ต้นน้ำถึงปลายน้ำ:

- [[01-requirements/index|01-requirements]] — ความต้องการของโปรเจกต์ ตั้งแต่สเปค แผนงาน ไปจนถึงงานย่อยที่ลงมือทำได้จริง
- [[02-design/index|02-design]] — การออกแบบ ทั้งต้นแบบหน้าตา UI/UX และการออกแบบเชิงเทคนิค
- [[03-testing/index|03-testing]] — การทดสอบระบบ ทั้งแผนการทดสอบและผลการทดสอบจริง
- [[04-retrospectives/index|04-retrospectives]] — สรุปบทเรียนหลังจบแต่ละ phase/sprint/milestone
- [[05-log/index|05-log]] — บันทึกความเคลื่อนไหวและเหตุการณ์สำคัญแบบเรียงตามลำดับเวลา
- [[00-archived/index|00-archived]] — เอกสารที่เลิกใช้งานแล้ว แต่เก็บไว้เพื่ออ้างอิงย้อนหลัง

โดยรวมแล้วงานจะไหลจาก **requirements → design → testing → retrospectives** ส่วน **log** จะถูกบันทึกคู่ขนานไปตลอดทั้งโปรเจกต์ และ **archived** เก็บทุกอย่างที่ถูกแทนที่หรือยกเลิกระหว่างทาง
