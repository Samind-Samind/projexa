## ความต้องการดิบ (Raw Requirement)

> SCR-023 สร้างเอกสารส่งมอบ: เลือกงวด + ประเภทเอกสาร → preview → แก้ไข → export .docx

## รายละเอียด (Detail)

- **รหัสหน้าจอ:** SCR-023
- **โมดูล:** M6 — จัดการเอกสาร
- **สถานะขอบเขต:** Must Have — อยู่ใน MVP โครงการ RAISE ลำดับที่ 13 (เหตุผล: ผลลัพธ์ปลายทาง) เอกสารที่ demo ในเฟสนี้คือ REQ และรายงานความก้าวหน้า (§10)
- **กระบวนการ (§8.1):** ดึงข้อมูลจริงจากฐานข้อมูล → ส่งเฉพาะเนื้อความบรรยายให้ AI (Document Writer) ร่าง → รวมเป็น JSON เดียว → เติมลง Template .dotx → preview → export .docx + บันทึกเวอร์ชัน

## Acceptance Criteria

- [ ] เลือกงวดงานและประเภทเอกสาร (REQ/รายงานความก้าวหน้า ในเฟสนี้) เพื่อสร้างเอกสาร
- [ ] ระบบดึงข้อมูลตาราง/ตัวเลข/เลขอ้างอิงจากฐานข้อมูลจริง ไม่ให้ AI เขียนตัวเลขเอง (§7.2, §8.2)
- [ ] AI ร่างเฉพาะเนื้อความบรรยาย และแสดง confidence ให้ผู้ใช้ตรวจ
- [ ] Preview เอกสารบนหน้าจอและแก้ไขได้ก่อน export
- [ ] Export เป็นไฟล์ .docx และบันทึกเวอร์ชันของเอกสาร (GeneratedDocument)
