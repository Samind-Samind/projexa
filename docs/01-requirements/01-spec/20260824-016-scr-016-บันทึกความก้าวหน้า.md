
# 016 — SCR-016 บันทึกความก้าวหน้า

- **วันที่สร้าง:** 2026-08-24
- **สถานะ:** Draft
- **ผู้ให้ requirement:** ไม่ระบุ (สกัดจากเอกสารออกแบบระบบ)
- **อ้างอิง TOR/เอกสารเดิม:** [Projexa-System-Design-R1.md](../../../Projexa-System-Design-R1.md) §5, §6 (M4)

## ความต้องการดิบ (Raw Requirement)

> SCR-016 บันทึกความก้าวหน้า: บันทึกสถานะ วันที่จริง % ความคืบหน้า หมายเหตุ แนบไฟล์รายขั้นตอน

## รายละเอียด (Detail)

- **รหัสหน้าจอ:** SCR-016
- **โมดูล:** M4 — ติดตามการดำเนินงาน
- **สถานะขอบเขต:** Must Have — อยู่ใน MVP โครงการ RAISE ลำดับที่ 11 (เหตุผล: ตรงตามความต้องการ)
- **กติกาวงจรสถานะที่เกี่ยวข้อง (§6):** ทุกครั้งที่เปลี่ยนสถานะ ระบบบังคับบันทึกผู้ทำรายการ วันเวลา สถานะเดิม→ใหม่ ผู้รับผิดชอบเดิม→ใหม่ เหตุผล (บังคับเมื่อเลื่อนวัน/ถอยสถานะ) และไฟล์แนบ

## Acceptance Criteria

- [ ] บันทึกสถานะปัจจุบันของหน้าจอ พร้อมวันที่จริง
- [ ] บันทึก % ความคืบหน้าและหมายเหตุ
- [ ] แนบไฟล์ประกอบในแต่ละขั้นตอนได้
- [ ] ทุกการเปลี่ยนสถานะบันทึกผู้ทำรายการและเวลาโดยอัตโนมัติ (ตาม §6)
