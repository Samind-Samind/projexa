## ความต้องการดิบ (Raw Requirement)

> SCR-014 ปฏิทินและการแจ้งเตือน: แจ้งเตือนงานใกล้ครบกำหนด/เลยกำหนด ตั้งค่าช่องทางแจ้งเตือน

## รายละเอียด (Detail)

- **รหัสหน้าจอ:** SCR-014
- **โมดูล:** M3 — วางแผนและมอบหมายงาน
- **สถานะขอบเขต:** นอกขอบเขต MVP โครงการ RAISE (Phase 2) — §10 ระบุว่า "เชื่อมต่อ LINE Notify / Email" เป็นนอกขอบเขตเฟสนี้ ซึ่งเป็นส่วนสำคัญของหน้าจอนี้

## Acceptance Criteria

- [ ] แสดงปฏิทินงานตามกำหนดการของหน้าจอ/งวดงาน
- [ ] แจ้งเตือนงานที่ใกล้ครบกำหนดและเลยกำหนดแล้ว
- [ ] ตั้งค่าช่องทางการแจ้งเตือนได้ (เช่น LINE Notify / Email)
