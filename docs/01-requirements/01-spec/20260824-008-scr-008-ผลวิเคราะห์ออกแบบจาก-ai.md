## รายละเอียด (Detail)

- **รหัสหน้าจอ:** SCR-008
- **โมดูล:** M2 — วิเคราะห์และออกแบบ
- **สถานะขอบเขต:** Must Have — อยู่ใน MVP โครงการ RAISE ลำดับที่ 7 (เหตุผล: จุดขายหลัก)
- **กติกา AI ที่เกี่ยวข้อง (§7.1):** Design Analyzer รับ REQ ที่ยืนยันแล้วเป็น input คืนค่า Actor/Flow/รายการหน้าจอ/ความสามารถ/business rule แต่ละรายการมี `source_req` ผู้ยืนยันคือ SA

## Acceptance Criteria

- [ ] แสดงข้อเสนอ Flow และรายการหน้าจอที่ AI วิเคราะห์จาก REQ ที่ยืนยันแล้ว
- [ ] แต่ละข้อเสนอมี `source_req` อ้างอิงกลับไปยัง Requirement ต้นทาง
- [ ] ผู้ใช้ (SA) ยืนยันหรือปรับแก้ได้รายรายการ ก่อนบันทึกเป็นทางการ
- [ ] รายการที่อ้างอิง REQ ไม่ได้ต้องติดป้าย `suggested`
