## TC-062 บันทึกผลการทดสอบ Pass/Fail รายรอบต่อ Test Case

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มี Test Case ที่ยืนยันแล้วอยู่ในทะเบียน (SCR-019) |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี Tester<br>2. เปิด Test Case ตัวอย่าง TC-สาธิต-01<br>3. รันตามขั้นตอน แล้วบันทึกผลเป็น "Fail" สำหรับรอบทดสอบที่ 1 |
| Expected Result | ระบบบันทึกผลการทดสอบ "Fail" ของรอบที่ 1 ไว้กับ Test Case นั้น |
| Test Data | ผลทดสอบ "Fail" รอบที่ 1 (ตัวอย่าง) |
| อ้างอิง AC | AC-020-1 |
| อ้างอิง Requirement | SCR-020 |

## TC-063 แนบหลักฐานการทดสอบได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้มีหลักฐานการทดสอบ (ภาพหน้าจอ error) จากการรัน Test Case ตาม TC-062 |
| Test Steps | 1. เปิดผลการทดสอบรอบที่ 1 ของ Test Case ตัวอย่าง<br>2. แนบไฟล์ `error-screenshot.png`<br>3. กดบันทึก |
| Expected Result | ระบบบันทึกไฟล์หลักฐาน `error-screenshot.png` ไว้กับผลการทดสอบของรอบนั้น |
| Test Data | ไฟล์ตัวอย่าง `error-screenshot.png` |
| อ้างอิง AC | AC-020-2 |
| อ้างอิง Requirement | SCR-020 |

## TC-064 ผูกผลทดสอบที่ Fail เข้ากับ Issue ได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผลการทดสอบรอบที่ 1 ของ Test Case ตัวอย่างเป็น "Fail" ตาม TC-062 |
| Test Steps | 1. เปิดผลการทดสอบรอบที่ 1 ที่เป็น "Fail"<br>2. ผูกผลทดสอบนี้เข้ากับ Issue "ปุ่มบันทึกไม่ตอบสนอง" (SCR-018)<br>3. กดบันทึก |
| Expected Result | ระบบบันทึกความสัมพันธ์ระหว่างผลทดสอบที่ Fail กับ Issue "ปุ่มบันทึกไม่ตอบสนอง" |
| Test Data | Issue "ปุ่มบันทึกไม่ตอบสนอง" (ตัวอย่างจาก SCR-018) |
| อ้างอิง AC | AC-020-3 |
| อ้างอิง Requirement | SCR-020, SCR-018 |
