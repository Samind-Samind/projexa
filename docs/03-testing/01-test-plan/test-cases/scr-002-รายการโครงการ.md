## TC-005 ค้นหาโครงการตามชื่อ/ลูกค้า

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีโครงการหลายรายการในระบบ รวมโครงการที่ชื่อ "โครงการตัวอย่าง A" และ "โครงการตัวอย่าง B" |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้ารายการโครงการ<br>3. กรอกคำค้นหา "ตัวอย่าง A" ในช่องค้นหา |
| Expected Result | ระบบแสดงเฉพาะโครงการที่ชื่อหรือลูกค้าตรงกับคำค้นหา "ตัวอย่าง A" |
| Test Data | คำค้นหา "ตัวอย่าง A" (ตัวอย่าง) |
| อ้างอิง AC | AC-002-1 |
| อ้างอิง Requirement | SCR-002 |

## TC-006 กรองรายการโครงการตามเงื่อนไข

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีโครงการหลายสถานะในระบบ (เช่น กำลังดำเนินการ, ปิดโครงการ) |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้ารายการโครงการ<br>3. เลือกเงื่อนไขกรองสถานะ "กำลังดำเนินการ" |
| Expected Result | ระบบแสดงเฉพาะโครงการที่มีสถานะ "กำลังดำเนินการ" |
| Test Data | เงื่อนไขกรอง "สถานะ = กำลังดำเนินการ" (ตัวอย่าง) |
| อ้างอิง AC | AC-002-2 |
| อ้างอิง Requirement | SCR-002 |

## TC-007 แสดงผลแบบแบ่งหน้า

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | จำนวนโครงการในระบบมากกว่าจำนวนที่แสดงได้ต่อหน้า (เช่น มี 25 โครงการ แสดงหน้าละ 10) |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้ารายการโครงการ<br>3. กดไปยังหน้าที่ 2 ของรายการ |
| Expected Result | ระบบแสดงแบบแบ่งหน้าและแสดงโครงการชุดที่ 11-20 เมื่ออยู่หน้าที่ 2 |
| Test Data | โครงการตัวอย่าง 25 รายการ (ตัวอย่าง) |
| อ้างอิง AC | AC-002-3 |
| อ้างอิง Requirement | SCR-002 |
