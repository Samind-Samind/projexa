## TC-070 เลือกงวดงานและประเภทเอกสาร (REQ/รายงานความก้าวหน้า) เพื่อสร้างเอกสาร

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | โครงการมีงวดงาน "งวดที่ 1" (SCR-007) และข้อมูล REQ ครบถ้วนแล้ว |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้าสร้างเอกสารส่งมอบ<br>3. เลือกงวดงาน "งวดที่ 1" และประเภทเอกสาร "REQ"<br>4. กดเริ่มสร้างเอกสาร |
| Expected Result | ระบบเริ่มกระบวนการสร้างเอกสาร REQ ของงวดงาน "งวดที่ 1" ตามที่เลือก |
| Test Data | งวดงาน "งวดที่ 1" ประเภทเอกสาร "REQ" (ตัวอย่าง) |
| อ้างอิง AC | AC-023-1 |
| อ้างอิง Requirement | SCR-023, SCR-007 |

## TC-071 ดึงข้อมูลตาราง/ตัวเลข/เลขอ้างอิงจากฐานข้อมูลจริง

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | โครงการมีรายการ REQ-001, REQ-002 บันทึกไว้จริงในฐานข้อมูล |
| Test Steps | 1. สร้างเอกสาร "REQ" ตาม TC-070<br>2. ตรวจสอบตารางรายการ REQ ในเอกสารที่สร้าง เทียบกับข้อมูลจริงในฐานข้อมูล |
| Expected Result | ตารางรายการ REQ ในเอกสารตรงกับ REQ-001, REQ-002 ที่มีอยู่จริงในฐานข้อมูลทุกตัวเลข/เลขอ้างอิง ไม่มีรายการที่ AI แต่งขึ้นเอง |
| Test Data | REQ-001, REQ-002 (ตัวอย่าง) |
| อ้างอิง AC | AC-023-2 |
| อ้างอิง Requirement | SCR-023 |

## TC-072 ป้องกันไม่ให้ AI เขียนตัวเลขเอง (negative case, suggested)

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | AI (Document Writer) ได้รับอนุญาตให้ร่างเฉพาะเนื้อความบรรยายตามกติกา §7.2/§8.2 |
| Test Steps | 1. จำลองกรณีที่ผลลัพธ์จาก AI มีตัวเลข/ตารางที่ AI แต่งขึ้นเองปนอยู่ในเนื้อความบรรยาย<br>2. ตรวจสอบ JSON ที่รวมก่อนเติมลง Template ว่ามีตัวเลข/ตารางนั้นหลุดเข้าไปหรือไม่ |
| Expected Result | ระบบต้องกรอง/ปฏิเสธตัวเลขหรือตารางที่ AI แต่งขึ้นเองออกก่อนรวมเป็น JSON เดียว ไม่ปล่อยให้หลุดเข้าสู่เอกสารที่ export จริง (suggested — ต้องรอ QA Lead/PM ยืนยันวิธีตรวจจับจริง) |
| Test Data | ข้อความ AI ตัวอย่างที่มีตัวเลขแต่งเอง เช่น "งบประมาณ 5,000,000 บาท" ที่ไม่มีในฐานข้อมูลจริง (ตัวอย่าง) |
| อ้างอิง AC | AC-023-2 |
| อ้างอิง Requirement | SCR-023 |
