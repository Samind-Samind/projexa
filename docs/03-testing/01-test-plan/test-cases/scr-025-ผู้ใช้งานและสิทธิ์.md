## TC-079 เพิ่ม/แก้ไข/ลบผู้ใช้งานในระบบได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้ (Admin) เปิดหน้าผู้ใช้งานและสิทธิ์ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี Admin<br>2. เพิ่มผู้ใช้งานใหม่ "สมปอง ทดสอบ (ตัวอย่าง)"<br>3. แก้ไขอีเมลของผู้ใช้งานนั้น<br>4. ลบผู้ใช้งานนั้นออก |
| Expected Result | ระบบบันทึกการเพิ่ม แก้ไข และลบผู้ใช้งาน "สมปอง ทดสอบ (ตัวอย่าง)" สำเร็จทั้ง 3 การกระทำ |
| Test Data | ผู้ใช้งานตัวอย่าง "สมปอง ทดสอบ (ตัวอย่าง)" |
| อ้างอิง AC | AC-025-1 |
| อ้างอิง Requirement | SCR-025 |

## TC-080 กำหนด Role ให้ผู้ใช้ได้ในระดับโครงการ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีผู้ใช้งาน "สมปอง ทดสอบ (ตัวอย่าง)" อยู่ในระบบและมีโครงการตัวอย่าง 1 โครงการ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี Admin<br>2. เปิดหน้าผู้ใช้งานและสิทธิ์<br>3. กำหนด Role "Tester" ให้ผู้ใช้งาน "สมปอง ทดสอบ" ในโครงการตัวอย่าง<br>4. กดบันทึก |
| Expected Result | ระบบบันทึก Role "Tester" ของ "สมปอง ทดสอบ" ในโครงการตัวอย่างนั้นสำเร็จ |
| Test Data | Role "Tester" (ตัวอย่าง) |
| อ้างอิง AC | AC-025-2 |
| อ้างอิง Requirement | SCR-025 |

## TC-081 หนึ่งผู้ใช้มีได้หลาย Role

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้งาน "สมปอง ทดสอบ" มี Role "Tester" อยู่แล้วในโครงการตัวอย่าง ตาม TC-080 |
| Test Steps | 1. เปิดหน้าผู้ใช้งานและสิทธิ์<br>2. เพิ่ม Role "Viewer" ให้กับ "สมปอง ทดสอบ" ในโครงการเดียวกัน<br>3. กดบันทึก |
| Expected Result | ระบบบันทึกให้ "สมปอง ทดสอบ" มีทั้ง Role "Tester" และ "Viewer" พร้อมกันในโครงการนั้น ตามที่ระบุใน §2 |
| Test Data | Role "Tester" + "Viewer" (ตัวอย่าง) |
| อ้างอิง AC | AC-025-3 |
| อ้างอิง Requirement | SCR-025 |
