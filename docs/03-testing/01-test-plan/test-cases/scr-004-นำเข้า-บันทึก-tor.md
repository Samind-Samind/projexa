## TC-012 อัปโหลดไฟล์ TOR ชนิด .docx/.pdf ที่มี text layer

| ฟิลด์ | รายละเอียด |
|---|---|

| Test Data | ไฟล์ TOR ตัวอย่าง `tor-sample.docx` (ตัวอย่าง มี text layer) |

| อ้างอิง Requirement | SCR-004 |

## TC-013 กรอกเนื้อหา TOR เองได้กรณีไม่มีไฟล์

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้ (PM) ไม่มีไฟล์ TOR แต่มีเนื้อหา TOR อยู่ในมือ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้านำเข้า/บันทึก TOR<br>3. เลือกโหมด "กรอกเนื้อหาเอง"<br>4. พิมพ์ข้อความ TOR ตัวอย่างลงในช่องข้อความ<br>5. กดบันทึก |
| Expected Result | ระบบรับเนื้อหาที่กรอกและใช้เป็นต้นทางสำหรับกระบวนการสกัดข้อมูลเช่นเดียวกับกรณีอัปโหลดไฟล์ |
| Test Data | ข้อความ TOR ตัวอย่าง "ข้อ 1. ผู้รับจ้างต้องจัดทำระบบ... (ตัวอย่าง)" |
| อ้างอิง AC | AC-004-2 |
| อ้างอิง Requirement | SCR-004 |

## TC-014 แสดงสถานะการสกัดของ AI

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้เพิ่งอัปโหลดไฟล์ TOR หรือกรอกเนื้อหา TOR เสร็จตาม TC-012/TC-013 |
| Test Steps | 1. สังเกตสถานะที่แสดงทันทีหลังส่ง TOR เข้าระบบ (ควรเป็น "กำลังประมวลผล")<br>2. รอจนกระบวนการสกัดเสร็จ สังเกตสถานะเปลี่ยนเป็น "เสร็จแล้ว"<br>3. (กรณีทดสอบ error) ส่งไฟล์ TOR ที่ทำให้การสกัดผิดพลาด แล้วสังเกตสถานะ |
| Expected Result | ระบบแสดงสถานะปัจจุบันของการสกัดตรงกับสถานะจริงของกระบวนการทั้ง 3 กรณี (กำลังประมวลผล/เสร็จแล้ว/ผิดพลาด) |
| Test Data | ไฟล์ TOR ตัวอย่างที่สกัดสำเร็จ และไฟล์ TOR ตัวอย่างที่จำลองให้สกัดผิดพลาด (ตัวอย่าง) |
| อ้างอิง AC | AC-004-3 |
| อ้างอิง Requirement | SCR-004 |
