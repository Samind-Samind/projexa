## TC-015 แสดงผลลัพธ์ AI คู่กับข้อความต้นฉบับ

|---|---|

## TC-016 ยืนยันรายการที่ AI สกัด

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีรายการที่ AI สกัดแสดงอยู่พร้อมป้าย `AI Generated` |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี BA<br>2. เปิดหน้าตรวจสอบผลสกัด TOR<br>3. กดยืนยันรายการแรกที่แสดงป้าย `AI Generated` |
| Expected Result | รายการนั้นเปลี่ยนป้ายจาก `AI Generated` เป็น `Human Confirmed` |
| Test Data | รายการสกัดตัวอย่างข้อ 1 (ตัวอย่าง) |
| อ้างอิง AC | AC-005-2 |
| อ้างอิง Requirement | SCR-005 |

## TC-017 แก้ไข เพิ่ม หรือลบรายการที่ AI สกัด

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีรายการที่ AI สกัดแสดงอยู่ซึ่งไม่ถูกต้องครบถ้วน |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี BA<br>2. เปิดหน้าตรวจสอบผลสกัด TOR<br>3. แก้ไขข้อความของรายการหนึ่ง<br>4. เพิ่มรายการใหม่ 1 รายการ<br>5. ลบรายการที่ไม่ถูกต้องออก 1 รายการ |
| Expected Result | ระบบบันทึกการแก้ไข/เพิ่ม/ลบทั้งหมด และรายการที่แสดงผลตรงกับที่ผู้ใช้แก้ไขล่าสุด |
| Test Data | รายการสกัดตัวอย่าง 3 รายการ (ตัวอย่าง) |
| อ้างอิง AC | AC-005-2 |
| อ้างอิง Requirement | SCR-005 |

## TC-018 ไม่มีข้อมูลถูกบันทึกจนกว่าจะยืนยัน (Human-in-the-loop)

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีรายการที่ AI สกัดแต่ยังไม่ถูกยืนยันโดยผู้ใช้เลย |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี BA<br>2. เปิดหน้าตรวจสอบผลสกัด TOR<br>3. ปิดหน้าโดยไม่กดยืนยันรายการใด<br>4. เปิดหน้าทะเบียนความต้องการ (SCR-006) |
| Expected Result | รายการที่ยังไม่ยืนยันต้องไม่ปรากฏในทะเบียนความต้องการ (SCR-006) อย่างเป็นทางการ |
| Test Data | รายการสกัดตัวอย่างที่ยังไม่ยืนยัน (ตัวอย่าง) |
| อ้างอิง AC | AC-005-3 |
| อ้างอิง Requirement | SCR-005, SCR-006 |

## TC-019 รายการที่อ้างอิงต้นทางไม่ได้ต้องติดป้าย suggested

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีรายการที่ AI สกัดแต่ไม่สามารถระบุ `source_clause` อ้างอิงกลับไปยังข้อความต้นฉบับได้ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี BA<br>2. เปิดหน้าตรวจสอบผลสกัด TOR<br>3. ตรวจสอบรายการที่ไม่มี `source_clause` |
| Expected Result | รายการที่ไม่มี `source_clause` ต้องติดป้าย `suggested` แยกให้ผู้ใช้พิจารณาต่างหากจากรายการที่มีต้นทางชัดเจน |
| Test Data | รายการสกัดตัวอย่างที่ไม่มี source_clause (ตัวอย่าง) |
| อ้างอิง AC | AC-005-4 |
| อ้างอิง Requirement | SCR-005 |
