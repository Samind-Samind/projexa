## TC-008 เพิ่มโครงการใหม่พร้อมข้อมูลครบ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้ (PM) อยู่ที่หน้าข้อมูลโครงการในโหมดสร้างใหม่ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้าข้อมูลโครงการ (สร้างใหม่)<br>3. กรอกชื่อโครงการ "โครงการตัวอย่าง (ข้อมูลสาธิต)" ลูกค้า "หน่วยงานตัวอย่าง (ข้อมูลสาธิต)" วันที่เริ่มต้น 24/08/2026 วันที่สิ้นสุด 28/02/2027 งบประมาณ 1,000,000 บาท และเพิ่มทีมงาน 3 คน<br>4. กดปุ่ม "บันทึก" |
| Expected Result | ระบบสร้างโครงการใหม่พร้อมข้อมูลทั้งหมดที่กรอก และแสดง toast "บันทึกข้อมูลโครงการสำเร็จ" ตามที่ prototype สาธิตไว้ |
| Test Data | ตามที่ระบุใน prototype `scr-003.html` — เป็นข้อมูลตัวอย่างเพื่อสาธิต UI ไม่ใช่ข้อมูลจริง |
| อ้างอิง AC | AC-003-1 |
| อ้างอิง Requirement | SCR-003 |

## TC-009 แก้ไขข้อมูลโครงการที่มีอยู่

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีโครงการ "โครงการตัวอย่าง (ข้อมูลสาธิต)" ที่มีงบประมาณ 900,000 บาท อยู่แล้วในระบบ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้าข้อมูลโครงการของโครงการดังกล่าว<br>3. แก้ไขงบประมาณจาก 900,000 เป็น 1,000,000 บาท<br>4. กดปุ่ม "บันทึก" |
| Expected Result | ระบบบันทึกงบประมาณใหม่ 1,000,000 บาททับค่าเดิม และแสดงค่านี้เมื่อเปิดหน้านี้อีกครั้ง |
| Test Data | งบประมาณเดิม 900,000 บาท → ใหม่ 1,000,000 บาท (ตัวอย่างตาม prototype) |
| อ้างอิง AC | AC-003-2 |
| อ้างอิง Requirement | SCR-003 |

## TC-010 บันทึกการเปลี่ยนแปลงลง audit log

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้แก้ไขงบประมาณโครงการจาก 900,000 เป็น 1,000,000 บาท ตาม TC-009 |
| Test Steps | 1. บันทึกการแก้ไขงบประมาณตาม TC-009<br>2. เปิดตาราง "ประวัติการเปลี่ยนแปลง (Audit Log)" ในหน้าเดียวกัน |
| Expected Result | ระบบบันทึกรายการลง audit log พร้อมวันที่/เวลา ผู้แก้ไข และข้อความ "แก้ไขงบประมาณโครงการ จาก 900,000 เป็น 1,000,000 บาท" ตามหลัก Everything is Logged |
| Test Data | ผู้แก้ไขตัวอย่าง "สมหญิง วิเคราะห์ (ตัวอย่าง)" เวลา 24/08/2026 14:32 |
| อ้างอิง AC | AC-003-3 |
| อ้างอิง Requirement | SCR-003 |

## TC-011 บังคับกรอกฟิลด์ที่จำเป็นก่อนบันทึก (suggested)

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้อยู่ที่แบบฟอร์มข้อมูลโครงการในโหมดสร้างใหม่ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้าข้อมูลโครงการ (สร้างใหม่)<br>3. เว้นฟิลด์ "ชื่อโครงการ" ไว้ว่าง แล้วกดปุ่ม "บันทึก" |
| Expected Result | ระบบแจ้งเตือนว่าต้องกรอกฟิลด์บังคับ และไม่บันทึกโครงการใหม่จนกว่าจะกรอกครบ (suggested — ต้องรอ BA/Tester ยืนยันพฤติกรรม validation จริง) |
| Test Data | เว้น "ชื่อโครงการ" ว่าง ฟิลด์อื่นกรอกครบ (ตัวอย่าง) |
| อ้างอิง AC | AC-003-4 |
| อ้างอิง Requirement | SCR-003 |
