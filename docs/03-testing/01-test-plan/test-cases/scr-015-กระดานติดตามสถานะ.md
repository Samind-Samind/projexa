## TC-047 ลากการ์ดเพื่อเปลี่ยนสถานะ พร้อมบังคับบันทึกเหตุผลเมื่อถอยสถานะ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | การ์ด SCR-A อยู่ที่คอลัมน์ "UAT" |
| Test Steps | 1. ลากการ์ด SCR-A จากคอลัมน์ "UAT" ถอยกลับไปที่คอลัมน์ "Development"<br>2. สังเกตว่าระบบบังคับให้กรอกเหตุผลก่อนบันทึกหรือไม่<br>3. กรอกเหตุผล "พบบั๊กสำคัญต้องแก้ก่อน" แล้วบันทึก |

| Test Data | เหตุผล "พบบั๊กสำคัญต้องแก้ก่อน" (ตัวอย่าง) |
| อ้างอิง AC | AC-015-2 |
| อ้างอิง Requirement | SCR-015 |
