## TC-040 กำหนดผู้รับผิดชอบ (SA/BA/Dev/Tester) รายหน้าจอได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้ (PM) เปิดหน้ามอบหมายผู้รับผิดชอบของหน้าจอ SCR-A |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้ามอบหมายผู้รับผิดชอบ<br>3. เลือกผู้รับผิดชอบ "สมชาย (Dev)" ให้กับหน้าจอ SCR-A<br>4. กดบันทึก |
| Expected Result | ระบบบันทึกผู้รับผิดชอบ "สมชาย (Dev)" ของหน้าจอ SCR-A ตามที่เลือก |
| Test Data | ผู้รับผิดชอบตัวอย่าง "สมชาย (Dev)" |
| อ้างอิง AC | AC-013-1 |
| อ้างอิง Requirement | SCR-013 |

## TC-041 มอบหมายผู้รับผิดชอบให้หลายหน้าจอพร้อมกันเป็นชุดได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีหน้าจอ SCR-A, SCR-B, SCR-C ที่ยังไม่มีผู้รับผิดชอบ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดทะเบียนหน้าจอ เลือกหน้าจอ SCR-A, SCR-B, SCR-C พร้อมกัน<br>3. มอบหมายผู้รับผิดชอบ "สมหญิง (Tester)" ให้ทั้งชุด<br>4. กดบันทึก |
| Expected Result | ระบบบันทึกผู้รับผิดชอบ "สมหญิง (Tester)" ให้กับหน้าจอ SCR-A, SCR-B, SCR-C พร้อมกันทั้งหมด |
| Test Data | หน้าจอ SCR-A/B/C, ผู้รับผิดชอบ "สมหญิง (Tester)" (ตัวอย่าง) |
| อ้างอิง AC | AC-013-2 |
| อ้างอิง Requirement | SCR-013 |

## TC-042 บันทึกการเปลี่ยนผู้รับผิดชอบลง audit trail

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | หน้าจอ SCR-A มีผู้รับผิดชอบเดิมคือ "สมชาย (Dev)" |
| Test Steps | 1. เปิดหน้ามอบหมายผู้รับผิดชอบของหน้าจอ SCR-A<br>2. เปลี่ยนผู้รับผิดชอบจาก "สมชาย (Dev)" เป็น "สมศักดิ์ (Dev)"<br>3. กดบันทึก<br>4. เปิดดูประวัติการเปลี่ยนแปลง (SCR-017) |
| Expected Result | ระบบบันทึกการเปลี่ยนแปลงลง audit trail พร้อมผู้รับผิดชอบเดิม "สมชาย (Dev)" และใหม่ "สมศักดิ์ (Dev)" |
| Test Data | ผู้รับผิดชอบเดิม/ใหม่ตามที่ระบุ (ตัวอย่าง) |
| อ้างอิง AC | AC-013-3 |
| อ้างอิง Requirement | SCR-013, SCR-017 |
