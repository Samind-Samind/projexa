## TC-027 แต่ละข้อเสนอมี source_req อ้างอิงกลับไปยัง Requirement ต้นทาง

## TC-028 SA ยืนยันหรือปรับแก้ได้รายรายการก่อนบันทึกเป็นทางการ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีข้อเสนอ Flow/หน้าจอที่ AI สร้างไว้และยังไม่ยืนยัน |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี SA<br>2. เปิดหน้าผลวิเคราะห์ออกแบบจาก AI<br>3. ปรับแก้ข้อเสนอรายการหนึ่ง แล้วกดยืนยัน<br>4. เปิดหน้าทะเบียนหน้าจอ (SCR-009) |
| Expected Result | เฉพาะรายการที่ผ่านการยืนยัน/ปรับแก้จาก SA เท่านั้นที่ถูกบันทึกเป็นทางการเข้าทะเบียนหน้าจอ (Gate 2) |
| Test Data | ข้อเสนอหน้าจอตัวอย่าง 2 รายการ (ยืนยัน 1, ไม่ยืนยัน 1) |
| อ้างอิง AC | AC-008-3 |
| อ้างอิง Requirement | SCR-008, SCR-009 |
