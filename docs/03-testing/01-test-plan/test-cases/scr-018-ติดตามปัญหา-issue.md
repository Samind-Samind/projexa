## TC-056 บันทึกปัญหา (Issue) พร้อมผลกระทบและแนวทางแก้ไข

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | ผู้ใช้ (Dev/Tester) พบปัญหาระหว่างการทำงานบนหน้าจอ SCR-A |
| Test Steps | 1. เข้าสู่ระบบ<br>2. เปิดหน้าติดตามปัญหา (Issue)<br>3. บันทึก Issue ใหม่ "ปุ่มบันทึกไม่ตอบสนอง" พร้อมผลกระทบ "ผู้ใช้บันทึกข้อมูลไม่ได้" และแนวทางแก้ไข "ตรวจสอบ event handler"<br>4. กดบันทึก |
| Expected Result | ระบบบันทึก Issue "ปุ่มบันทึกไม่ตอบสนอง" พร้อมผลกระทบและแนวทางแก้ไขที่กรอกไว้ครบถ้วน |
| Test Data | Issue ตัวอย่างข้างต้น |
| อ้างอิง AC | AC-018-1 |
| อ้างอิง Requirement | SCR-018 |

## TC-057 กำหนดผู้รับผิดชอบและติดตามสถานะของ Issue ได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มี Issue "ปุ่มบันทึกไม่ตอบสนอง" ที่บันทึกไว้แล้วตาม TC-056 และยังไม่ได้กำหนดผู้รับผิดชอบ |
| Test Steps | 1. เปิดรายละเอียด Issue "ปุ่มบันทึกไม่ตอบสนอง"<br>2. กำหนดผู้รับผิดชอบเป็น "สมชาย (Dev)"<br>3. เปลี่ยนสถานะเป็น "กำลังแก้ไข"<br>4. กดบันทึก |
| Expected Result | ระบบบันทึกผู้รับผิดชอบ "สมชาย (Dev)" และสถานะ "กำลังแก้ไข" ของ Issue นั้น |
| Test Data | ผู้รับผิดชอบ "สมชาย (Dev)" สถานะ "กำลังแก้ไข" (ตัวอย่าง) |
| อ้างอิง AC | AC-018-2 |
| อ้างอิง Requirement | SCR-018 |
