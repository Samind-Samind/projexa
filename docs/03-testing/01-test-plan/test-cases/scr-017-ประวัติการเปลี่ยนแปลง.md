## TC-052 แสดง timeline ประวัติการเปลี่ยนสถานะและผู้รับผิดชอบของหน้าจอ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | หน้าจอ SCR-A มีประวัติการเปลี่ยนสถานะ/ผู้รับผิดชอบบันทึกไว้แล้วจาก SCR-013/SCR-016 |
| Test Steps | 1. เข้าสู่ระบบ<br>2. เปิดหน้าประวัติการเปลี่ยนแปลงของหน้าจอ SCR-A |
| Expected Result | ระบบแสดง timeline ของการเปลี่ยนสถานะและผู้รับผิดชอบของ SCR-A ตามลำดับเวลาจริง |
| Test Data | ประวัติการเปลี่ยนแปลงตัวอย่างของ SCR-A (ตัวอย่าง) |
| อ้างอิง AC | AC-017-1 |
| อ้างอิง Requirement | SCR-017 |

## TC-053 แสดงเหตุผลของการเปลี่ยนแปลงแต่ละครั้ง

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีรายการเปลี่ยนแปลงที่เป็นการถอยสถานะพร้อมเหตุผลที่บังคับกรอกไว้ (ตาม TC-047) |
| Test Steps | 1. เปิดหน้าประวัติการเปลี่ยนแปลงของ SCR-A<br>2. เปิดดูรายละเอียดของรายการที่ถอยสถานะ |
| Expected Result | ระบบแสดงเหตุผล "พบบั๊กสำคัญต้องแก้ก่อน" ที่บันทึกไว้ของการเปลี่ยนแปลงนั้น |
| Test Data | เหตุผลตัวอย่าง "พบบั๊กสำคัญต้องแก้ก่อน" |
| อ้างอิง AC | AC-017-2 |
| อ้างอิง Requirement | SCR-017 |

## TC-054 ดูย้อนหลังได้ทั้งหมดตั้งแต่เริ่มโครงการ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | โครงการมีประวัติการเปลี่ยนแปลงสะสมมาตั้งแต่วันเริ่มโครงการ |
| Test Steps | 1. เปิดหน้าประวัติการเปลี่ยนแปลงของ SCR-A<br>2. เลื่อนดูรายการที่เก่าที่สุด (วันเริ่มโครงการ) |
| Expected Result | ระบบแสดงประวัติทั้งหมดย้อนหลังได้จนถึงวันเริ่มโครงการ โดยไม่มีข้อมูลใดถูกลบทิ้ง |
| Test Data | ประวัติสะสมตั้งแต่ 24/08/2026 (ตัวอย่าง) |
| อ้างอิง AC | AC-017-3 |
| อ้างอิง Requirement | SCR-017 |

## TC-055 ข้อมูลชุดนี้นำไป generate เป็นรายงานความก้าวหน้าได้

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีข้อมูลประวัติการเปลี่ยนแปลงสะสมอยู่ในระบบ |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้าสร้างเอกสารส่งมอบ (SCR-023)<br>3. เลือกประเภทเอกสาร "รายงานความก้าวหน้า"<br>4. ตรวจสอบเนื้อหาที่ประกอบขึ้นในเอกสาร |
| Expected Result | เอกสาร "รายงานความก้าวหน้า" มีเนื้อหาที่ดึงมาจากประวัติการเปลี่ยนแปลงของ SCR-017 จริง |
| Test Data | ประวัติการเปลี่ยนแปลงตัวอย่างของ SCR-A (ตัวอย่าง) |
| อ้างอิง AC | AC-017-4 |
| อ้างอิง Requirement | SCR-017, SCR-023 |
