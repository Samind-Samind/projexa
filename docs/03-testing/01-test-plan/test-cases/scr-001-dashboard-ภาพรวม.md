## TC-001 แสดงสรุปภาพรวมโครงการจากข้อมูลจริง

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | มีโครงการอยู่ในระบบแล้วอย่างน้อย 1 โครงการ พร้อมข้อมูลสถานะจริง |
| Test Steps | 1. เข้าสู่ระบบด้วยบัญชี PM<br>2. เปิดหน้า Dashboard ภาพรวม |
| Expected Result | ระบบแสดงจำนวนโครงการและสถานะของแต่ละโครงการ โดยตัวเลขตรงกับข้อมูลจริงในระบบ ไม่ใช่ตัวเลขที่ AI สร้างขึ้นเอง |
| Test Data | โครงการตัวอย่าง "โครงการตัวอย่าง (ข้อมูลสาธิต)" — ไม่ใช่ข้อมูลจริง |
| อ้างอิง AC | AC-001-1 |
| อ้างอิง Requirement | SCR-001 |

## TC-002 แสดง % ความก้าวหน้าของแต่ละโครงการ

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | โครงการมีข้อมูลความก้าวหน้าที่บันทึกไว้แล้วจาก SCR-016/SCR-017 |

| Expected Result | ระบบแสดง % ความก้าวหน้าของแต่ละโครงการตรงกับข้อมูลความก้าวหน้าที่บันทึกไว้จริง |
| Test Data | โครงการตัวอย่างที่มีความก้าวหน้า 40% (ตัวอย่าง) |
| อ้างอิง AC | AC-001-2 |
| อ้างอิง Requirement | SCR-001 |
