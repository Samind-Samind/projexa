## TC-065 รวมไฟล์แนบและเอกสารทั้งหมดของโครงการไว้ที่เดียว

| ฟิลด์ | รายละเอียด |
|---|---|
| Pre-condition | โครงการมีไฟล์แนบจาก SCR-016 (ไฟล์ประกอบความก้าวหน้า) และเอกสารส่งมอบจาก SCR-023 กระจายอยู่คนละหน้าจอ |
| Test Steps | 1. เข้าสู่ระบบ<br>2. เปิดหน้าคลังเอกสารโครงการ |
| Expected Result | ระบบแสดงไฟล์แนบและเอกสารทั้งหมดของโครงการรวมไว้ที่หน้าเดียว ครบทั้งไฟล์จาก SCR-016 และ SCR-023 |
| Test Data | ไฟล์แนบตัวอย่างจาก SCR-016 และเอกสารตัวอย่างจาก SCR-023 |
| อ้างอิง AC | AC-021-1 |
| อ้างอิง Requirement | SCR-021 |
